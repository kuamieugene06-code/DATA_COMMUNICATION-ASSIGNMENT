What I Studied

Core concepts from signals to application-layer protocols

📡

Signals & Transmission

The foundation of all communication. Data must be converted into a signal before it can travel.

  • Analog signals — continuous waveforms
  • Digital signals — discrete 0s and 1s
  • Bandwidth and data rate
  • Attenuation, noise, and distortion
  • Transmission media: copper, fibre optic, wireless
  • Simplex, half-duplex, and full-duplex modes
🔗

Data Link Layer

Responsible for reliable node-to-node delivery of data frames between two directly connected devices.

  • Framing — packaging bits into frames
  • Error detection: parity bits, CRC
  • Error correction: Hamming codes
  • Flow control: Stop-and-Wait, Sliding Window
  • MAC addressing
  • Protocols: HDLC, PPP, Ethernet
🌐

Network Layer & IP

Handles logical addressing and routing of packets from source to destination across multiple networks.

  • IPv4 and IPv6 addressing
  • Subnetting and CIDR notation
  • Packet switching vs circuit switching
  • Routing algorithms: RIP, OSPF, BGP
  • NAT — Network Address Translation
  • ICMP and ARP protocols
🚚

Transport Layer

Provides end-to-end communication between applications running on different hosts.

  • TCP — reliable, connection-oriented
  • UDP — fast, connectionless
  • Port numbers and sockets
  • Three-way handshake (SYN, SYN-ACK, ACK)
  • Congestion control and flow control
  • Multiplexing and demultiplexing
🔐

Security & Encryption

Protecting data as it travels across potentially untrusted networks.

  • Symmetric encryption: AES, DES
  • Asymmetric encryption: RSA, public/private keys
  • TLS/SSL handshake process
  • Digital signatures and certificates
  • Firewalls and intrusion detection
  • Common attacks: MitM, DoS, phishing
📶

Wireless & Mobile Networks

Communication without physical cables using radio waves and other wireless technologies.

  • Wi-Fi standards: 802.11a/b/g/n/ac/ax
  • Cellular generations: 2G, 3G, 4G LTE, 5G
  • Bluetooth and NFC
  • OFDM modulation technique
  • Spread spectrum: FHSS, DSSS
  • Challenges: interference, handover, range
📚

OSI & TCP/IP Models

Layered frameworks that standardise how different systems communicate with each other.

  • 7 OSI layers: Physical to Application
  • 4 TCP/IP layers and how they map
  • Encapsulation and de-encapsulation
  • Role of each layer with examples
  • PDUs: bits, frames, packets, segments
  • Why layered models matter in IT
⚙️

Application Layer Protocols

Protocols that directly support end-user applications and services on the internet.

  • HTTP and HTTPS — web communication
  • DNS — domain name resolution
  • SMTP, POP3, IMAP — email protocols
  • FTP and SFTP — file transfer
  • DHCP — dynamic IP assignment
  • SSH — secure remote access

The Electric Telegraph

1837 — the first electrical data communication system

The telegraph (1837) was the world's first electrical data communication system, encoding text as Morse code pulses over wire — the earliest ancestor of every modern network.

  1. 1837 Electric telegraph — Morse code over wire
  2. 1876 Telephone — voice over electrical signals
  3. 1969 ARPANET — packet-switched networking
  4. Today 5G, fibre, cloud — global digital infrastructure
